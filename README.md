# Zkouška A2 nanečisto

Тренувальний симулятор іспиту з чеської мови A2 для трвалого побиту (новий формат від 11. 4. 2026).

- 20 варіантів, кожен запуск збирає новий іспит з випадкових завдань
- Čtení, Psaní, Poslech (озвучення голосом браузера), Mluvení
- Режими «Іспит» (таймери) і «Тренування»

Сайт: https://andre-kuvich14g.github.io/zkouska-a2/

Навчальний матеріал, не офіційний іспит NPI ČR.

## Мовні версії (UA · EN · RU · VI)
Джерело — `index.html` (українська). Після кожної зміни в ньому запускати:

    python3 tools/build_i18n.py

Скрипт створює `en/`, `ru/`, `vi/` і оновлює `sitemap.xml`. Переклади інтерфейсу — `tools/i18n_tr.py`,
пояснень до відповідей — `tools/why_tr.py`. Якщо в `index.html` з'явився новий український текст,
скрипт зупиниться й покаже, для якого фрагмента бракує перекладу (`python3 tools/i18n_extract.py`).

## Дата «оновлено»
Дата в блоці «Що нового» на стартовій сторінці ставиться автоматично (сьогоднішня дата за Прагою) щоразу, коли запускається `python3 tools/build_i18n.py`. Тож після будь-яких змін на сайті просто перезберіть мовні версії.
