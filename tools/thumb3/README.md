# Обкладинки v3 (з 12.11.2026)
Мультяшна сцена на весь фон + кольорова панель úlohy зліва.
- Великими жовтими: тема ЧЕСЬКОЮ (1–2 рядки, автопідгін шрифту).
- Під нею дрібно білим: переклад українською (з tr.json → uk.title).
- Внизу: тип завдання чеською («FORMULÁŘ · 8 BODŮ»), zkouska-a2.cz; праворуч зверху номер «N/40».
- Підсумки/загальні: обсяг («50 OTÁZEK · TÉMATA 1–5») + плашка з 5 темами + «VELKÉ OPAKOVÁNÍ».
Нове відео: додати сцену в scenes2.js (з kit.js), запис у all.json → `node tc2.js all.json out3 <id>`.
